# Игра

## Атомарные механики

| code                       | атомарное действие          | над чем работает | описание                                    |
| -------------------------- | --------------------------- | ---------------- | ------------------------------------------- |
| MOVE\_TO\_DECK             | Переместить карту в Deck    | Card             | Положить карту в колоду с указанием позиции |
| MOVE\_TO\_HAND             | Переместить карту в Hand    | Card, Player     | Передать карту в руку игрока                |
| MOVE\_TO\_STABLE           | Переместить карту в Stable  | Card, Player     | Поместить карту в стойло игрока             |
| MOVE\_TO\_DISCARD          | Переместить карту в Discard | Card             | Отправить карту в сброс                     |
| MOVE\_TO\_NURSERY          | Переместить карту в Nursery | Card             | Отправить малыша в ясли                     |
| DRAW\_FROM\_DECK           | Взять верхнюю карту         | Player           | Игрок берёт карту из Deck                   |
| DISCARD\_FROM\_HAND        | Сбросить карту с руки       | Player           | Игрок выбирает карту и сбрасывает           |
| SACRIFICE\_FROM\_STABLE    | Пожертвовать из стойла      | Player           | Игрок уничтожает карту у себя               |
| DESTROY\_IN\_STABLE        | Уничтожить в чужом стойле   | Player → Player  | Уничтожить карту цели                       |
| STEAL\_FROM\_STABLE        | Украсть из стойла           | Player → Player  | Переместить карту в своё стойло             |
| SEARCH\_IN\_DECK           | Найти карту в Deck          | Player           | Поиск по условию                            |
| SEARCH\_IN\_DISCARD        | Найти карту в Discard       | Player           | Поиск по условию                            |
| SHUFFLE\_DECK              | Перемешать Deck             | Game             | Изменить`deck_order`                        |
| SKIP\_PLAYER\_TURN         | Пропуск хода                | Player           | Следующий ход игрока пропускается           |
| PROTECT\_STABLE            | Защитить стойло             | Player           | Запрет на DESTROY/SACRIFICE                 |
| RESTRICT\_CARD\_PLAY       | Запрет играть тип карт      | Player           | Ограничение на розыгрыш                     |
| TRIGGER\_ON\_TURN\_START   | Триггер начала хода         | Player           | Запуск сценария в начале хода               |
| TRIGGER\_ON\_ENTER\_STABLE | Триггер входа в стойло      | Card             | Запуск сценария при входе                   |
| TRIGGER\_ON\_LEAVE\_STABLE | Триггер выхода из стойла    | Card             | Запуск сценария при выходе                  |
| COUNT\_AS\_UNICORN         | Считается единорогом        | Card             | Учитывается для победы                      |
