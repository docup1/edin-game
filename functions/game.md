# Игра

Ход партии: снимок состояния, определение победителя, старт и сам ход — [`diagrams/game.mmd`](../diagrams/game.mmd).

| № | Функция | Принимает | Возвращает | Что делает | Зачем нужна |
|---|---|---|---|---|---|
| 1 | [`fn_get_game_state`](../db/20_functions.sql#L545) | `p_id_game bigint, p_id_player bigint DEFAULT NULL` | `jsonb` | Полное состояние: ход, текущий игрок, колода, сброс, игроки со стойлами (единороги/защита/запрет), победа; плюс рука/доступные для конкретного игрока | Основной снимок игры для клиента |
| 2 | [`fn_check_victory`](../db/20_functions.sql#L620) | `p_id_game bigint` | `jsonb` | Победа по единорогам (порог 7 при 2–5 игроках, 6 при 6); при пустой колоде — тай-брейк по единорогам, затем по длине имён | Определение победителя |
| 3 | [`sp_start_game`](../db/20_functions.sql#L1010) | `p_id_game bigint` | `jsonb` | Раздаёт по 5 карт (первому при открытии хода — 6), ставит `move_status`, открывает ход; повторный старт/мало игроков → `ED003`, мало карт → `ED004` | Начало игры |
| 4 | [`sp_begin_turn`](../db/20_functions.sql#L1049) | `p_id_game bigint, p_skip_player bigint DEFAULT NULL` | `jsonb` | Открывает ход: определяет игрока (пропуская `p_skip_player`), добирает карту, запускает turn-start, отдаёт `available`; не началась → `ED003` | Открытие хода |
| 5 | [`sp_skip_turn`](../db/20_functions.sql#L1086) | `p_id_game bigint` | `jsonb` | Фиксирует ход за текущим игроком и сразу открывает следующий; не началась → `ED003` | Пропуск хода |
| 6 | [`sp_apply_event`](../db/20_functions.sql#L1103) | `p_id_game bigint, p_turn int, p_request_id text, p_do text, p_id_card bigint, p_target bigint DEFAULT NULL` | `void` | Разыгрывает или сбрасывает карту текущего игрока с проверками (номер хода, карта в руке, действие, цель). Актор не передаётся — это всегда текущий игрок; «не его ход» проверяет сервер. Устаревший номер хода → `ED003`, карты нет в руке → `ED004`, не участник партии → `ED002` | Игровое действие (204) |
| 7 | [`sp_end_turn`](../db/20_functions.sql#L1141) | `p_id_game bigint, p_turn int` | `void` | Завершает ход текущего игрока: автосброс лишних (>7), фиксирует ход, затем `sp_begin_turn`; устаревший ход → `ED003` | Конец хода (204) |
