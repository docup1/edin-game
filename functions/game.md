# Игра

Внутренние хелперы `_*` и ход партии в одном домене — [`diagrams/game.mmd`](../diagrams/game.mmd). Верхние строки (`_*`) служебные: их зовут только другие функции БД, в публичный API они не входят. Движок механик и порядок хода — кандидаты на вынос на сервер.

| № | Функция | Принимает | Возвращает | Что делает | Зачем нужна |
|---|---|---|---|---|---|
| 1 | [`_card_mechanics`](../db/20_functions.sql#L48) | `p_id_card bigint` | `SETOF mechanic_name_enum` | Возвращает механики карты через её шаблон (`template_mechanics`) | Проверка и применение эффектов карты |
| 2 | [`_has_mechanic`](../db/20_functions.sql#L58) | `p_id_card bigint, p_name mechanic_name_enum` | `boolean` | Есть ли у карты указанная механика | Условия на механики (победа, защита, триггеры) |
| 3 | [`_move_card`](../db/20_functions.sql#L73) | `p_id_player bigint, p_id_card bigint, p_zone text` | `void` | Универсальное перемещение карты в `hand`/`stable`/`deck`/`discard` без запуска leave-триггера | Один примитив вместо `_to_hand`/`_to_stable`/`_to_deck`/`_discard_card` |
| 4 | [`_cards_in_zone`](../db/20_functions.sql#L101) | `p_id_game bigint, p_zone text, p_id_player bigint DEFAULT NULL` | `SETOF bigint` | Универсальный список карт зоны: `hand`/`stable` (для игрока), `deck` (остаток колоды), `discard` (сброс партии) | Один примитив вместо `_hand`/`_stable`/`_deck_card_ids` |
| 5 | [`_game_started`](../db/20_functions.sql#L129) | `p_id_game bigint` | `boolean` | Читает `games.move_status` | Единая проверка «партия уже началась» |
| 6 | [`_lock_game`](../db/20_functions.sql#L135) | `p_id_game bigint, p_require_started boolean DEFAULT false` | `void` | Берёт партию под `FOR UPDATE`; если партии нет — `ED001`, а при `p_require_started` и не начавшейся партии — `ED003` | Сериализует конкурентные изменения одной партии |
| 7 | [`_player_status`](../db/20_functions.sql#L151) | `p_id_player bigint` | `jsonb` | Сводка стойла одним запросом: `unicorns`, `protected` (`PROTECT_STABLE`), `restricted` (`RESTRICT_CARD_PLAY`) | Замена `_player_unicorns`/`_is_protected`/`_is_restricted` |
| 8 | [`_next_player`](../db/20_functions.sql#L164) | `p_id_game bigint, p_id_player bigint` | `bigint` | Следующий игрок по `move_order` (циклично); при `NULL` — первый | Передача хода по кругу |
| 9 | [`_current_player`](../db/20_functions.sql#L176) | `p_id_game bigint` | `bigint` | Чей сейчас ход: следующий по кругу после игрока, чей ход завершён последним | Определение текущего игрока |
| 10 | [`_turn_number`](../db/20_functions.sql#L190) | `p_id_game bigint` | `int` | Номер открытого хода = `count(moves по игре) + 1` | Проверка актуальности хода и счётчик |
| 11 | [`_record_move`](../db/20_functions.sql#L199) | `p_id_player bigint` | `void` | Записывает завершённый ход игрока (`max(move_number)+1`) | Фиксация хода `sp_end_turn`/`sp_skip_turn` |
| 12 | [`_fire_leave_stable`](../db/20_functions.sql#L209) | `p_id_card bigint` | `void` | Запускает `TRIGGER_ON_LEAVE_STABLE` при выходе карты из стойла (лимит глубины 5) | Срабатывание «выход из стойла» (зовётся явно только на DESTROY/SACRIFICE) |
| 13 | [`_draw`](../db/20_functions.sql#L241) | `p_id_game bigint, p_id_player bigint` | `bigint` | Берёт случайную карту из колоды в руку; `NULL`, если колода пуста | Добор карт |
| 14 | [`_apply_active_mechanics`](../db/20_functions.sql#L267) | `p_id_game bigint, p_actor bigint, p_id_card bigint, p_target bigint, p_lenient boolean` | `void` | Применяет активные механики карты (DRAW/DISCARD/SACRIFICE/DESTROY/STEAL/SEARCH/SHUFFLE/SKIP); в lenient-режиме ошибки — только warning | Исполнение эффектов карты |
| 15 | [`_apply_play`](../db/20_functions.sql#L378) | `p_id_game bigint, p_actor bigint, p_id_card bigint, p_target bigint` | `void` | Разыгрывает карту: разовые эффекты → итоговая зона (`MOVE_TO_*`) → enter-триггер | Логика розыгрыша карты |
| 16 | [`_available`](../db/20_functions.sql#L426) | `p_id_game bigint, p_id_player bigint` | `jsonb` | Карты руки, доступные к розыгрышу, с флагом цели и списком целей; пусто, если не ваш ход или есть RESTRICT (приватный, отдаётся внутри `fn_get_game_state`) | Подсказка «что можно сыграть» |
| 17 | [`fn_get_game_state`](../db/20_functions.sql#L508) | `p_id_game bigint, p_id_player bigint DEFAULT NULL` | `jsonb` | Полное состояние: ход, текущий игрок, колода, сброс, игроки со стойлами (единороги/защита/запрет), победа; плюс рука/доступные для конкретного игрока | Основной снимок игры для клиента |
| 18 | [`fn_check_victory`](../db/20_functions.sql#L583) | `p_id_game bigint` | `jsonb` | Победа по единорогам (порог 7 при 2–5 игроках, 6 при 6); при пустой колоде — тай-брейк по единорогам, затем по длине имён | Определение победителя |
| 19 | [`sp_start_game`](../db/20_functions.sql#L973) | `p_id_game bigint` | `jsonb` | Раздаёт по 5 карт (первому при открытии хода — 6), ставит `move_status`, открывает ход; повторный старт/мало игроков → `ED003`, мало карт → `ED004` | Начало игры |
| 20 | [`sp_begin_turn`](../db/20_functions.sql#L1012) | `p_id_game bigint, p_skip_player bigint DEFAULT NULL` | `jsonb` | Открывает ход: определяет игрока (пропуская `p_skip_player`), добирает карту, запускает turn-start, отдаёт `available`; не началась → `ED003` | Открытие хода |
| 21 | [`sp_skip_turn`](../db/20_functions.sql#L1057) | `p_id_game bigint` | `jsonb` | Фиксирует ход за текущим игроком и сразу открывает следующий; не началась → `ED003` | Пропуск хода |
| 22 | [`sp_apply_event`](../db/20_functions.sql#L1074) | `p_id_game bigint, p_turn int, p_request_id text, p_do text, p_id_card bigint, p_target bigint DEFAULT NULL` | `void` | Разыгрывает или сбрасывает карту текущего игрока с проверками (номер хода, карта в руке, действие, цель). Актор не передаётся — это всегда текущий игрок; «не его ход» проверяет сервер. Устаревший номер хода → `ED003`, карты нет в руке → `ED004`, не участник партии → `ED002` | Игровое действие (204) |
| 23 | [`sp_end_turn`](../db/20_functions.sql#L1112) | `p_id_game bigint, p_turn int` | `void` | Завершает ход текущего игрока: автосброс лишних (>7), фиксирует ход, затем `sp_begin_turn`; устаревший ход → `ED003` | Конец хода (204) |
